開始使用

下載安裝腳本 → 一鍵裝好 → 用瀏覽器開本機頁面就能開始。

  1. 下載腳本 — 取得 LinkinL 安裝包（Mac / Linux；Windows 請先用 WSL2）。
  2. 一鍵安裝 — 執行 ./scripts/install.sh，程式會裝在你電腦的資料夾。
  3. 開網頁 — 依教學啟動後，用瀏覽器開本機網址即可使用 AI 幫手。
給進階使用者：終端機指令 
git clone https://github.com/iiooiioo888/LinkinL.git
cd LinkinL && chmod +x scripts/*.sh
./scripts/install.sh
