誰在哪裡跑 · 資料留在本機

LinkinL 只負責安裝與說明。對話、金鑰、工具 trace 與 OPC 讀數落在 clone 下來的 Linkin 工作目錄，不進這個官網倉。

LinkinL

官網倉 · 本 repo
  • index.html / docs — 產品敘事與錨點
  • scripts/install.sh — clone Linkin、寫 linkinl.json
  • scripts/update.sh — pull master、印 commit 差
  • 不含 FastAPI、前端原始碼、API 金鑰

linkin-runtime

預設 ./linkin-runtime · Linkin master
  • python -m backend.main — API :8000
  • frontend npm run dev — Vite :3001
  • Redis :6379 · Chroma :8100 · OPC :8001
  • .env — 金鑰只放這個目錄，勿提交

金鑰

OPENAI_API_KEY、LINKIN_GATE、REDIS_PASSWORD 寫在 runtime 的 .env，官網範本 .env.linkinl.example 只有路徑和埠。

Trace

工具呼叫與產出物封存在本機 archive。重播看的是自己機器上的 run，不是雲端對話紀錄。

工業寫入

OPC 讀數可進公司路徑；寫入仍要過 opc_service/guard.py，模擬與正式開關在 runtime。

update.sh 示意 · 非即時查詢
舊 linkin_commit → 新 HEAD · 快轉後印出領先的 commit
manifest：linkinl.json · branch master · installed_at / updated_at
