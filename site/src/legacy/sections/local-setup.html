怎麼安裝

在 Mac 或 Linux 打開終端機，複製下面指令即可（Windows 請先用 WSL2）。安裝腳本會另抓 Linkin 主程式 到本機資料夾，金鑰只寫在那裡，不經過這個官網。 

git clone https://github.com/iiooiioo888/LinkinL.git
cd LinkinL && chmod +x scripts/*.sh
./scripts/install.sh

LinkinL = 說明與安裝腳本（這個網站）。linkin-runtime = 真正跑智能助手的工作目錄。詳細步驟見 getting-started。
