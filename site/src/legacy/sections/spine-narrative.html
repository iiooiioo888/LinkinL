LinkinL 是什麼？

外骨骼不取代你下判斷，而是把 Agent 執行、護欄與證據鏈穿在本機 runtime 上——像工業外骨骼放大力量，但力矩與止點由你設定。

可證明

每一跳工具與封存可重播

不是聊天截圖：trace id、預算決策、產出 hash 留在本機帳本。

有護欄

Token / GPU hard stop

L03 在執行路徑上設止點，多 Agent 並行也不會 silent 燒穿配額。

本機資料

金鑰與向量不過官網

LinkinL 只負責安裝敘事；runtime、Chroma、Redis 在你的 linkin-runtime 目錄。
