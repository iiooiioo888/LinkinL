四層執行架構（L04 → L01）

LinkinL 將多 Agent 編排敘事為由上而下四層堆疊；頁面左側 72px rail 與產品區 SVG 皆為 L04 → L03 → L02 → L01 順序。

總覽

層級名稱職責
L04AI 執行層LangGraph 管線、本機 Agent 執行與反思閉環
L03預算層token / GPU / 成本 metering，超限即停
L02共識層append-only 產出物帳本（CID + hash chain）
L01組件層vLLM、SGLang、LangGraph、Ray、Chroma 等 OSS 栈

Hero 執行 DAG（L04 語意）

  1. 意圖解析
  2. 檢索
  3. 工具呼叫
  4. KV 快取
  5. 預算檢查
  6. 產出物封存
  7. 輸出

官網 trace-stage 上的 RE-RUN 會依序點亮 DAG 節點與邊，示範可重播軌跡。
