本機執行 Linkin

LinkinL 官網說明產品與架構；實際運行時請使用 Linkin 主倉。

1. Clone 主倉

git clone https://github.com/iiooiioo888/Linkin.git
cd Linkin

2. 環境需求

工具版本
Python3.12+
Node.js20+
Docker可選（Redis、Chroma 或整棧）

3. 方式 A — Docker Compose

情境指令
全棧docker compose up -d
只起 Redis 與 Chromadocker compose up -d redis chroma

詳見主倉 docs/deployment/guide.md 與 DEPLOYMENT.md。

4. 方式 B — 本機 Python + 前端

python3 -m venv .venv
source .venv/bin/activate   # Windows: .venv\Scripts\Activate.ps1
pip install -r requirements.txt

cp .env.example .env
# 填入 API 金鑰

# 後端 http://localhost:8000
python -m backend.main

# 另開終端：前端 http://localhost:3001
cd frontend && npm install && npm run dev

可選：先起依賴再跑後端（與官網 terminal 區塊一致）：

docker compose up -d redis chroma
python -m backend.main

5. 埠號速查

服務埠
前端（Vite）3001
後端 API8000
OPC8001
Redis6379
Chroma8100
