本機執行 Linkin

LinkinL 官網（GitHub Pages）說明產品與架構；運行時使用 Linkin 主倉（master）。以下含 install.sh / update.sh 流程。

平台

環境建議
macOS / Linux直接執行 bash 腳本
Windows請用 WSL2；未正式支援原生 PowerShell

0. Clone LinkinL

git clone https://github.com/iiooiioo888/LinkinL.git
cd LinkinL
chmod +x scripts/install.sh scripts/update.sh

1. 安裝 Linkin（install.sh）

預設 clone 到 ./linkin-runtime，並寫入 linkinl.json（branch、commit、時間）。可設 LINKIN_DIR=~/Linkin 或 --shallow。

./scripts/install.sh

LINKIN_DIR=~/Linkin ./scripts/install.sh --shallow
./scripts/install.sh --check-only

cp .env.linkinl.example .env.linkinl
cd linkin-runtime && cp .env.example .env

2. 更新 Linkin（update.sh）

./scripts/update.sh
./scripts/update.sh --npm

會顯示 commit 差異與近期 log。

3. 環境需求

工具版本
Python3.12+
Node.js20+
Docker可選（Redis、Chroma 或整棧）
git近期版本

4. 方式 A — Docker Compose

在 Linkin 目錄（例如 linkin-runtime）：

情境指令
全棧docker compose up -d
只起 Redis 與 Chromadocker compose up -d redis chroma

詳見主倉 docs/deployment/guide.md 與 DEPLOYMENT.md。

5. 方式 B — 本機 Python + 前端

cd linkin-runtime
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

# 後端 http://localhost:8000
python -m backend.main

# 另開終端：前端 http://localhost:3001
cd frontend && npm install && npm run dev

可選：

docker compose up -d redis chroma
python -m backend.main

6. 埠號速查

服務埠
前端（Vite）3001
後端 API8000
OPC8001
Redis6379
Chroma8100

.env.linkinl.example 含 OPC_SIM_* 等開發註解。
